Instalacao

  1. 1Build

    npm install && astro build && node scripts/generate-og.mjs

    saida: dist/ (~36s, 380 páginas)

    As OG images saem de satori + @resvg/resvg-js, 1200x630, com as fontes em scripts/fonts/.

  2. 2Deploy

    git push origin main

    saida: GitHub Actions publica em github.io/opendex

    Workflow em .github/workflows/deploy.yml, dispara no push para main.

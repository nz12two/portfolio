instalação

Passo a passo

1

Build

npm install && astro build && node scripts/generate-og.mjs

saída: dist/ (~36s, 380 páginas). As OG images saem de satori + @resvg/resvg-js, 1200×630, com as fontes em scripts/fonts/.

2

Deploy

git push origin main

saída: GitHub Actions publica em github.io/opendex. Workflow em .github/workflows/deploy.yml, dispara no push para main.

o padrão de dado

Catálogo real, não vitrine de mentira

Plugins, scripts e MCPs derivam dos dados reais do npm (249 pacotes). Repositórios vêm de um coletor real do GitHub (123 repos).

Quando não há fonte, a página mostra empty state honesto em vez de inventar item. Essa foi a regra depois da auditoria que removeu 12 entradas fake.

News é reconstruída de 9 releases reais do GitHub + 30 posts do Dev.to.

O layout de catálogo, o coletor e o gerador de OG são reusados por este catálogo de produtos.

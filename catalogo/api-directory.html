API Directory

Diretório de APIs públicas gratuitas que diz se elas respondem, com latência medida.

Para quem e

  • Quem procura endpoint grátis e precisa saber se ainda funciona antes de integrate.
  • Quem já toma low-level timeout do servidor e quer separar 'fora do ar' de 'CORS bloqueando' — o site responde as duas perguntas separadamente.

Instalacao

  1. 1Rodar a sondagem

    python tools/probe_apis.py

    saida: data/health.json

    16 workers, ~3 min. Roda no CI uma vez por dia.

  2. 2Gerar o dataset

    python tools/build_dataset.py

    saida: data/apis.json

    Catálogo + tradução PT. O site carrega JSON estático — a tradução acontece uma vez, não no navegador de cada visitante.

Por que a latência não é medida no navegador

Porque o navegador mentiria. Um fetch só entrega o corpo se o servidor mandar Access-Control-Allow-Origin; sem isso o browser bloqueia e reporta 'failed' — sem distinguir servidor fora do ar de CORS barrando.

São duas perguntas diferentes, então a sondagem responde as duas: tools/probe_apis.py no CI mede se o host responde e em quantos ms; o botão ▶ no navegador diz se dá para consumir no front.

Quando o ▶ falha mas a sondagem diz HTTP 200, as duas informações aparecem lado a lado — e as duas estão certas.

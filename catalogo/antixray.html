AntiXray

Detecção modular de x-ray para Paper 1.21.4+, com 19+ detectores e motor de risco temporal.

Beta Minecraft gratuito MIT

Compila e empacota (verificado em JDK 21). Em desenvolvimento: os detectores ainda precisam de ajuste de taxa de falso positivo em servidor real e o projeto não tem suíte de testes. Não use em produção sem revisar os thresholds de risco.

Para quem e

  • Dono de servidor Paper que loses ores e não sabe quemminerou.
  • Administrador que precisa de evidência, não só de kick: o plugin salva replay dos últimos 5 minutos e gera evidência automática no flag.
  • Quem integra: há API pública (AntiXrayAPI) e eventos para plugin próprio.

Instalacao

  1. 1Compilar o jar

    .\gradlew.bat shadowJar

    saida: build/libs/AntiXray-2.0.0.jar

    Requer JDK 21. Verificado: exit 0, 909 KB.

  2. 2Jogar na pasta plugins/

    copie build/libs/AntiXray-2.0.0.jar para <servidor>/plugins/

    Reinicie o servidor. Os 18 módulos registram no console em sequência.

  3. 3Configurar

    copie config.example.yml para plugins/AntiXray/config.yml e ajuste os thresholds

    Este passo é o que separa uso em teste de uso em servidor com jogador. Os thresholds de risco são o produto, não um detalhe.

Como funciona o pipeline de detecção

A coleta (block break, movimento, sessão) alimenta a extração de features: 25+ features de mineração pré-computadas por jogador.

Os 19+ detectores rodam em 3 tiers — Fast, Medium, Heavy — com dependências entre eles. Detector rápido descarta o óbvio; o pesado só entra quando o risco já subiu.

O Risk Engine pontua de forma temporal: risco atual + anterior + histórico. Um pico isolado não pune; um padrão sustentado, sim.

A punishível é configurável: log, warn, kick, ban, freeze ou comando próprio. Evidence gera o relatório e Replay guarda os últimos 5 minutos de dados do jogador no momento do flag.

Discord recebe embed rico por webhook, com rate limiting — para não inundar o canal de quem responde.

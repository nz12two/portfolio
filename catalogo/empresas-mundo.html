EmpresasMundo

Simulação de empresas de entrega competindo por fitness: cada uma é um agente com rede neural recorrente própria, num grafo do OpenStreetMap.

estável gratuito sem licença Python · FastAPI · OSMnx

Roda local. Sem deploy público e sem licença no repositório — GPL implícito por omissão, o que é ambíguo.

para quem é

Para quem é

  • Quem quer ver agent-based modeling funcionando em mapa real: São Paulo via OSMnx.
  • Quem estuda routing evolucionário — o DNA de cada empresa (estratégia, agressividade, velocidade) evolui ao longo das gerações.

instalação

Passo a passo

1

Dependências

cd backend && python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt

Windows. Em Linux: python -m venv .venv && source .venv/bin/activate.

2

Subir o servidor

.venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000

saída: http://localhost:8000. FastAPI + WebSocket. O frontend conecta e desenha o mapa.

arquitetura

Como está montado

  • backend/main.py — servidor FastAPI + WebSocket.
  • backend/map_data.py — carrega o grafo de ruas pelo OSMnx.
  • backend/simulation.py — motor de simulação tick a tick.
  • backend/company.py — classe Empresa, o agente com DNA.
  • frontend/ — interface, lógica de WebSocket e estilo.
